# Longest Positive Streak

A simple Python function to find the length of the longest consecutive streak of positive numbers in a list of integers.

## Installation

```bash
pip install longest_positive_streak
```

## Usage

```python
from longest_positive_streak import longest_positive_streak

nums = [1, 2, -3, 4, 5, 6, 0, 7, 8]
streak = longest_positive_streak(nums)
print(f"The longest positive streak is: {streak}")
```
